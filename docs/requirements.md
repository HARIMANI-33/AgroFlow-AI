# AGROFLOW AI - System Requirements & Design Foundations

## Problem Statement
"Multiple intermediaries reduce farmers earnings and increase consumer prices." (Smart India Hackathon)

## Key Product & Language Requirements

### 1. Multilingual First-Screen Flow
* **First Screen View**:
  * Role Selection: **Farmer** or **Buyer**
  * Language Toggle (Top Corner): **தமிழ்** (Tamil) and **English**
* **Selection Precedence**:
  * The user selects their preferred language before entering Login/Register.
  * The selected language applies globally across all screens and user workflows.
* **Unified Codebase**:
  * This is a single multilingual web application, not two separate applications.

### 2. Planned Core Capabilities
* Direct farmer-buyer marketplace
* Real-time mandi/market pricing integration
* Buyer-demand-first matching algorithms
* Bulk order demand aggregation
* Future harvest and pre-harvest forward contracts
* Crop visual verification through photo uploads
* Smart crop advisory & recommendations
* Minimalist, farmer-friendly user interface
